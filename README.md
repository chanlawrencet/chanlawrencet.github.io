# chanlawrencet.github.io
Personal website, made with React

Link to site: [https://www.chanlawrencet.com](https://www.chanlawrencet.com)

This project was bootstrapped with [Create React App](https://github.com/facebook/create-react-app).

## Deployment

To deploy changes:
1. Make your changes in `src/` or `public/`
2. Build: `export NODE_OPTIONS=--openssl-legacy-provider && yarn build`
3. Copy build files: `cp -r build/* .`
4. Commit and push to master

The site deploys automatically from the master branch.
